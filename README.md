## 🚀 How to Run Locally

Since this website is built with native web technologies with zero dependencies, you can run it immediately without any setup:

### Option 1: Double Click
Simply double-click `index.html` in your file explorer to open it in your default web browser (Chrome, Edge, Firefox, Brave, Safari).

### Option 2: VS Code Live Server
If you use VS Code, install the **Live Server** extension, right-click `index.html`, and select **Open with Live Server**.

## 🌐 Free Deployment Guide

### Deploying to GitHub Pages
1. Create a new repository on GitHub named `portfolio` (or `username.github.io`).
2. Push the files inside `h:/Portfolio/` to your repository:
   ```bash
   git init
   git add .
   git commit -m "Initial portfolio commit"
   git branch -M main
   git remote add origin https://github.com/<your-username>/<repo-name>.git
   git push -u origin main
   ```
3. In GitHub, navigate to **Settings** > **Pages**.
4. Under **Branch**, select `main` and root `/`, then click **Save**.
5. Your portfolio will be live at `https://<your-username>.github.io/<repo-name>/` in a minute!

### Deploying to Netlify or Vercel
- Drag and drop the `Portfolio` folder directly onto [Netlify Drop](https://app.netlify.com/drop) or import from GitHub into Vercel for instant automated deployment with custom domain support.
